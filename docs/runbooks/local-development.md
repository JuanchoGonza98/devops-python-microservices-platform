# Local Development Runbook

## Objetivo

Describir cómo preparar y ejecutar el proyecto en entorno local durante las primeras fases.

## Estado actual

En esta etapa el repositorio contiene la estructura base del proyecto y la documentación inicial.

## Próximos pasos previstos

1. crear esqueletos de los microservicios
2. levantar el primer servicio localmente
3. incorporar Docker
4. levantar el stack con Docker Compose

## Requisitos esperados

- Git
- Python 3.12
- Docker
- Docker Compose
- Make

## Convenciones

- cada servicio vivirá dentro de `services/`
- cada servicio tendrá su propio `Dockerfile`
- la documentación debe mantenerse alineada con el estado real del proyecto
- no se avanzará a la siguiente fase sin cerrar la anterior

## Validación inicial

La validación de esta fase consiste en comprobar:

- estructura de carpetas creada
- documentos base presentes
- repositorio listo para inicializar con Git
